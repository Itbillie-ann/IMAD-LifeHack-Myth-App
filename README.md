# Myth / Life Hack Quiz App

# Overview
This Android app presents users with a series  of true/false questions about myths and life

## Features
- True/False quiz system
- Score tracking
- Answer review
- Simple UI

## How It Works
1. User answers a series of questions
2. App evaluates responses
3. Displays score
4. Highlights incorrect answers

## Technologies Used
- Java/Kotlin
- Android Studio
